# GSSC ERP CMS System (Odoo v17)

A comprehensive ERP solution developed using **Odoo 17** to replace the traditional record-keeping system (Tredtinola) at **Government Superior Science College (GSSC)**.

---

## Project Overview

The existing record-keeping system at GSSC was manual and outdated, causing inefficiencies in managing student records, attendance, and other administrative tasks. This project delivers a modern, automated ERP system tailored specifically for the college's needs.

---

## Features

- **Student Management:** Maintain detailed student records including personal info, enrollment, and academic history.
- **Attendance Tracking:** Automated attendance system for students and staff.
- **Course and Class Management:** Manage courses, class schedules, and assignments.
- **Administrative Tools:** Simplify staff roles, permissions, and daily operations.
- **Reporting:** Generate comprehensive reports on student performance, attendance, and administrative activities.
- **User-friendly Interface:** Easy navigation tailored for non-technical college staff.

---

## Technologies Used

- **Odoo 17** — ERP framework and backend
- **Python** — Module development and business logic
- **PostgreSQL** — Database management
- **XML & QWeb** — Views and report templates
- **JavaScript** — Interactive UI components
